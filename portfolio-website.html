Overview

I built this portfolio as a live multi-page front-end site with shared styling, project detail pages, and lightweight JavaScript interactions. Its job is to present my background in a more professional way while also acting as an ongoing web project that I can keep refining.

  • Shared front-end structure

    Uses consistent layouts, navigation, visual styling, and reusable sections across the homepage, About, Projects, Contact, and project detail pages. In October 2026 I rebuilt it on my own design system, so every page draws from one shared set of colours, type and components.

  • Interactive UI work

    Includes a network-map homepage where each node lights up its links, a filterable changelog on the About page, a scrolling how-it-works diagram on the Jarvis page, a contact form flow that opens Gmail or a mail app, and a phone menu that folds the page links into one button.

  • Content organization and iteration

    The site keeps changing as my projects, school background, and presentation choices get updated, so it also shows how I revise content and improve structure over time.

Current build highlights

  • Homepage

    Uses a network map with my photo at the center and my projects, school, work and honors around it, so the first thing employers see is how everything connects.

  • About page

    Tells my background as a changelog with filters, then breaks skills, certificates and organizations into focused sections so they are easier to scan.

  • Projects page

    Lists my projects on one page, with Jarvis featured first, for quicker browsing.

  • Jarvis page

    Adds a scroll-driven how-it-works diagram, with a simpler vertical version on phones.

  • Look and motion

    Light forest and sage colours, one set of shape markers across the pages, and view transitions between pages that switch off for visitors who prefer reduced motion.

Where it can grow next

The clearest next improvements are adding screenshots to more project pages, expanding project-specific visuals, and continuing to sharpen the writing as the portfolio grows.

Why it matters

This project matters because it is not only something I built. It is also the main surface employers use to evaluate how I present work, organize information, and keep a live project updated as my background changes.
