Overview

I built this portfolio as a live multi-page front-end site with shared styling, project detail pages, and lightweight JavaScript interactions. Its job is to present my background in a more professional way while also acting as an ongoing web project that I can keep refining.

  • Shared front-end structure Uses consistent layouts, navigation, visual styling, and reusable sections across the homepage, About, Skills, Projects, Contact, and project detail pages. In October 2026 I rebuilt it on my own design system, so every page draws from one shared set of colours, type and components.
  • Interactive UI work Includes a featured-project homepage section, searchable project directory, certificate cards on the About page, contact form flow that opens Gmail or a mail app, and a phone menu that folds the page links into one button.
  • Content organization and iteration The site keeps changing as my projects, school background, and presentation choices get updated, so it also shows how I revise content and improve structure over time.

Current build highlights

  • Homepage Uses a featured-project grid to surface the builds I want employers to see first.
  • About and Skills pages Breaks the site into focused sections so background, certificates, and strengths are easier to scan.
  • Projects directory Uses JavaScript-rendered project cards with search and category filters for quicker browsing.

Where it can grow next

The clearest next improvements are adding screenshots to more project pages, expanding project-specific visuals, and continuing to sharpen the writing as the portfolio grows.

Why it matters

This project matters because it is not only something I built. It is also the main surface employers use to evaluate how I present work, organize information, and keep a live project updated as my background changes.
