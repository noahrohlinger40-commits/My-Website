Overview

Jarvis is my own take on a desktop AI assistant, and I keep building on it. It combines a Windows Forms app, a C#/.NET 8 assistant runtime, voice input and output, memory, reminders, web research, screen-aware tooling, and desktop automation into one local Windows system.

  • Multi-part application structure

    The project is split between Jarvis.Core for planning, memory, tool dispatch, and safety logic, plus Jarvis.App for the Windows UI, microphone pipeline, wake-word flow, and live operations surface.

  • Speech and local-model experimentation

    Supports wake-word detection, speech recognition, text to speech, memory recall, and live assistant interaction while comparing local LM Studio models against cloud-backed OpenAI-compatible options.

  • Testing and iteration

    The project was tested against app launching, reminders, research, screen reading, memory workflows, and automation reliability, with the project writeup documenting what worked, what broke, and why.

STEP 01

The wake word

Jarvis does nothing until it hears its name.

Wake-word detection uses a DSP profile for each microphone, plus acoustic echo suppression and clap detection. I built the calibration tools after it started responding to its own speaker.

STEP 02

Speech becomes text

Recognition runs on a local speech server.

My voice stays on the machine.

STEP 03

The planner decides

Jarvis.Core handles tool calling, intent routing and reflection.

It talks to a model gateway that speaks OpenAI-compatible APIs, so it can use a local model in LM Studio or a cloud one.

STEP 04

It picks a tool

One of 67 tools, from files and the browser to Office and weather.

Memory is one of them, and it is inspectable: JSON storage, semantic search and retention policies, so old activity ages out without losing preferences.

STEP 05

Destructive actions wait for me

Nothing destructive runs without my approval.

Shell use is opt-in, and protected paths (Windows, System32, Program Files, HKLM) are hard-blocked. API keys live in environment variables or Windows Credential Manager.

STEP 06

It answers out loud

Text to speech reads the result back.

What it looks like

What is in v1.0.0

v1.0.0 is the first public source release, published September 21, 2026. It covers 71 source files and roughly 50,900 lines across the two main components.

  • Jarvis.Core, the assistant engine

    A planner handling tool calling, intent routing, and reflection, with 67 assistant tools spanning files, shell, window management, browser control, media, messaging, email, Office integration, memory, reminders, research, and weather.

  • Memory and automation

    A memory subsystem with JSON storage, semantic search, retention policies, and privacy controls, plus desktop automation through Win32 UI Automation.

  • Model gateway and safety layer

    Compatible with OpenAI-style endpoints and local runtimes, with approval gates in front of destructive operations.

  • Jarvis.App, the Windows Forms host

    Multiple voice runtimes including realtime transcription and Windows Speech, wake-word detection with microphone-specific DSP profiles and calibration, acoustic echo suppression, clap detection, and memory and presence workbenches with an operations HUD.

  • Biggest changes in this release

    Speech recognition moved from a cloud provider to a local speech server, and the planner moved to a larger locally hosted model across all four roles.

  • Known limitations

    No automated tests or CI pipeline yet, Windows only (net8.0-windows with WinForms), and full offline operation needs a local model endpoint and speech server running.

Where it can grow next

My end goal is a secure and private AI that does a lot more than my basic tasks: controlling the Bluetooth and Wi-Fi devices in my apartment, talking to it from my phone when I'm on the go, and running it on an AI model I train myself instead of LM Studio. Closer in, the next steps are more reliable structured tool use on local models, cleaner automation of modern apps, a proper installer, and calendar and email integrations.
