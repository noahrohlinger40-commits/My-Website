Matchob

Matchob is a Chrome extension my team at FSU's AWS Cloud Club is building to tailor a resume to a job posting. I lead the AI team, and my focus is making sure it never suggests something the resume cannot back up.

Python, AWS Lambda and SAM, Amazon Bedrock, DynamoDB, and TypeScript with React.

AI team lead: planning the AI work each sprint, building the guardrails, and reviewing the team's pull requests.
Current state
Sprint 1 finished October 16, 2026. Sprint 2 connects the matching to the model, and the team demo is November 20.

Overview

You paste in a job description and upload your resume. Matchob finds what each requirement asks for, finds the resume lines that match, and suggests clearer wording. Every suggestion gets one of three labels: Supported, Needs Confirmation, or Unsupported.

  • Truthful by design

    A suggestion only counts as Supported if its facts are already in the resume. Anything it cannot check goes back to the user to confirm, and anything invented is marked Unsupported and cannot be accepted.

  • Five teams, one contract

    Frontend, Backend, AI, Data and QA each own a piece, and shared JSON contracts let each team build and test on its own.

  • Reviewed changes

    Every change goes through a branch and a pull request on GitHub and is reviewed before it merges.

The flow

  1. Posting + resume
  2. Requirements
  3. Matching lines
  4. Suggested wording
  5. Span check
  6. Supported / Needs Confirmation / Unsupported

What I built

  • Guardrails

    A span check and claim finder that compare each suggestion with the original resume text, matching whole words and numbers so "led" never matches "scheduled" and "3" never matches "2023".

  • Attack tests

    36 made-up claims written to slip past the guardrails, such as invented numbers, titles and tools. All 36 get the right label, and the AI code has 120 automated tests.

  • Test resumes and mock answers

    Three fictional resumes and six mock answers, so the Frontend team could build the review screen before the model was connected.

Where it goes next

Sprint 2 connects the matching to Amazon Bedrock and adds the prompts that write the suggestions, with the team demo on November 20, 2026.

Why it matters
